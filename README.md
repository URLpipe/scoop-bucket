# URLpipe Scoop bucket

```powershell
scoop bucket add urlpipe https://github.com/URLpipe/scoop-bucket
scoop install urlpipe
```

`urlpipe` turns any URL into Markdown, rendered HTML, a screenshot, metadata, console errors or a Lighthouse audit, from the terminal. Pages are rendered in real Chrome.

The manifest here is written by the release workflow of [URLpipe/urlpipe-go](https://github.com/URLpipe/urlpipe-go); don't edit it by hand. Docs: https://urlpipe.dev/docs/client-libraries
